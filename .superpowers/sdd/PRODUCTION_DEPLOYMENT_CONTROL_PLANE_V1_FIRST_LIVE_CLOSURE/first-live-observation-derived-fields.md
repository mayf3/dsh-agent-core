This preflight proves the actual physical prerequisites only. It does not publish an admission configuration or claim a future executed denial.

Use a narrowly typed internal maintenance input that validates all fixed identities, labels, argv, loaded/disabled flags, plist hashes, service generations and phase-appropriate loader preimages/postimages under the existing grant and guard. Those values then pass all existing admission validators and are published with the same guarded pending-adoption fence. Policy/grant/config/enrollment digests are calculated from these actual final values, never from a caller assertion about future outputs. A failed or partial lifecycle cannot construct the bound values, sign authority or enable admission.

Tests must reject caller-supplied derived fields and incomplete/failed observation state, prove exact physical-template preservation in the final constructed values, and show that the maintenance route cannot create admission state. Final source/package review covers this composition. No source/template object is represented as executed production evidence.
