## Minimal selected implementation

1. To enroll the existing complete app face, permit literal `@` as one more safe nonseparator character in the shared component validator. Preserve exact `.`/`..` rejection, NUL/separator/absolute/path-depth/size restrictions and descriptor nofollow ownership checks. No `+`, `=`, `$` or depth increase is needed in the routine target/artifact API. Routine mutation still requires the exact existing mutable slot allowlist (Watchdog/Broker only). Add genuine negative traversal/alias/symlink tests plus a real scoped-name regular-file roundtrip; canonical old serialized bytes remain unchanged.
2. The one-shot bootstrap metadata walker handles the separate complete fixed harness inventory via a dedicated finite-inventory path parser. It permits only the explicitly observed safe literal component characters, max14components/max242bytes or stricter bound sufficient for the frozen inventory, exact package membership, no empty/dot/dotdot/NUL/slash component, no absolute path. It never passes these names to shell, command arguments, glob expansion or mutable caller-selected filesystem destinations. This does not widen shared routine artifact grammar.
3. Preserve the3 exact internal hardlink pairs rather than unlink/rewrite/chown an unknown alias. Before any metadata change, protected descriptor traversal must prove the complete exact inventory, each expected device/inode/nlink/hash/mode/owner/flags/ACL and group multiplicity. The entire observed link count must equal the closed enumerated group; every member must be in the same protected frozen harness and have identical preimage. Unknown, external, added, missing or metadata/content-drifted alias aborts. The operator isolates ancestors first, journals one inode metadata transition with all pair members, revalidates each held member/path before/after and verifies nlink remains2. No content/link topology change is authorized. Recovery compares the exact current group before restoring metadata once. A generic allow-hardlinks flag or weakening fs::secure::validate is forbidden; ordinary artifact, key, grant, state, journal and app files continue nlink1.

This addition does not make a partial inventory sufficient, does not waive quiescence or concurrent-writer checks, and does not authorize any effect now. Native source and final packet review must include these directly affected path/closed-alias checks. Tests use fixture trees only, including an extra external alias that must fail before metadata mutation. Before implementation, independent bounded design review must confirm these choices still satisfy accepted trust/complete-face/legacy adoption contracts.
